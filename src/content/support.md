# Support

Ways to get help and support NgMd.

## Community support <ngmd-badge variant="stable">MIT</ngmd-badge>

NgMd is MIT-licensed and open source. Start here.

<ngmd-card-grid columns="2">
  <ngmd-card icon="shield" title="Bug reports" link="https://github.com/erkamyaman/ngmd/issues">
    File an issue when something doesn't work as documented.
  </ngmd-card>
  <ngmd-card icon="lightbulb" title="Feature requests" link="https://github.com/erkamyaman/ngmd/issues">
    Propose new components, primitives, or workflows.
  </ngmd-card>
  <ngmd-card icon="compass" title="Discussions" link="https://github.com/erkamyaman/ngmd/discussions">
    Ask questions, share patterns, show what you built.
  </ngmd-card>
  <ngmd-card icon="code" title="Pull requests" link="https://github.com/erkamyaman/ngmd/pulls">
    Contribute fixes, docs, or new features.
  </ngmd-card>
</ngmd-card-grid>

## Sponsorship

If your team relies on NgMd, consider sponsoring:

<ngmd-card-grid columns="3">
  <ngmd-card icon="sparkles" title="One-time">
    GitHub Sponsors single contribution. Buy the maintainer a few hours.
  </ngmd-card>
  <ngmd-card icon="zap" title="Recurring">
    Monthly support to keep the project healthy and the release cadence steady.
  </ngmd-card>
  <ngmd-card icon="rocket" title="Logo placement">
    Logo on the site for sponsoring organisations at qualifying tiers.
  </ngmd-card>
</ngmd-card-grid>

Sponsorship funds documentation, releases, and the time to keep the stack working with the latest *Angular and *AnalogJS versions.

## Paid support <ngmd-badge variant="beta">Coming soon</ngmd-badge>

Private consulting and enterprise support packages are on the horizon for teams that need:

<ngmd-accordion>
  <ngmd-accordion-item title="Migration help">
    Docusaurus, VitePress, or Storybook docs to NgMd. Information architecture, content port, and theming pass.
  </ngmd-accordion-item>
  <ngmd-accordion-item title="Custom theming and branding">
    Design-system tokens applied across NgMd's component vocabulary, plus the site frame to match your brand guidelines.
  </ngmd-accordion-item>
  <ngmd-accordion-item title="Component primitives for your design system">
    New authoring components built for patterns specific to your product. Owned by you, source in your repo.
  </ngmd-accordion-item>
  <ngmd-accordion-item title="SLA-backed bug-fix turnarounds">
    Defined response times for issues that block your release. Contractual commitment, not best-effort.
  </ngmd-accordion-item>
</ngmd-accordion>

Reach out via GitHub if you'd like to start a conversation.

## Reporting security issues

<ngmd-alert severity="critical">
  Do <strong>not</strong> open a public GitHub issue for security reports. Email the maintainer directly so the issue can be triaged before disclosure.
</ngmd-alert>
