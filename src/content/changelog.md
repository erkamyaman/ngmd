# Changelog

Release notes and version history for NgMd.

## Unreleased

- Initial v0 scaffolding
- Landing page with hero, feature grid, and stack badges
- AnalogJS markdown content collections wired
- Spartan UI brain installed; helm-style placeholder card
- Shiki code highlighting (`bash`, `md`, `json`, `ts`, `html`, `css`)
- Tailwind v4 with class-based dark mode
- Light/dark/auto theme cycle with no flash on refresh
- Cmd+K command palette
- Code-block copy buttons
- Right-side on-page TOC with active heading tracking
- Mobile drawer for sidebar navigation
- Breadcrumb derived from route
- Translucent sticky header (`backdrop-blur-sm`)

## v0.1 (planned)

- Config-driven navigation
- Branding tokens (extended theme system)
- Landing page primitives (hero, feature grid, CTA blocks) as reusable components
- More component vocabulary (callouts, code-block tabs, pill rows)
- Right-side in-page TOC with auto-generated id anchors
- Real Spartan helm command palette

## v1 (later)

- npm publish as `@ngmd/core`, `@ngmd/theme`, `@ngmd/cli`
- `npx create-ngmd` scaffolder
- Versioning support
- i18n
- Search adapter (Orama offline + Algolia DocSearch optional)
