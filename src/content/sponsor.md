# Sponsor NgMd

NgMd is free MIT software maintained in the open. If it saves you time, here's how to keep it healthy.

## The easiest way

<ngmd-callout type="tip" title="Star the repo">
  The lowest-effort way to support an OSS project: <a href="https://github.com/erkamyaman/ngmd" target="_blank" rel="noopener noreferrer">⭐ leave a star on GitHub</a>. Free, instant, and surfaces NgMd to other Angular developers searching for a docs starter.
</ngmd-callout>

After that, also free: write up what you built, link back to the repo, file good bug reports, contribute a PR. All of these are gold.
